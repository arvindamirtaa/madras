# Logo photograph

`public/assets/beach-waves.jpg` is an overhead photograph of waves meeting a sandy shoreline by Hameen Reynolds, downloaded from [Unsplash](https://unsplash.com/photos/aerial-view-of-waves-crashing-on-a-sandy-beach-zWFa7mlQAYk) at 960 pixels wide. It is a general beach photograph, not a photograph of Chennai.

The photograph is available under the [Unsplash License](https://unsplash.com/license). CSS crops it to fill the letter shapes; the downloaded image is otherwise unmodified. The website footer credits the photographer and links to the original photograph.

The masked wordmark uses plain CSS. If the image cannot load, its dark background colour fills the letters. Browsers without text clipping and forced colour modes show readable solid text.
